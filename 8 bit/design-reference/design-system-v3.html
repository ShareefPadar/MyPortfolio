The gate — which face
IS IT READ AS
A SENTENCE?
YES →Geist. At any size. Case study titles, headings, captions, body.
NO →Label or statement?
LABEL →Departure Mono. Tags, meta, eyebrows, nav links, captions on data.
STATEMENT →Silkscreen. Five words max. Hero, page titles, numerals, buttons.
Why — heading level describes structure; the face describes reading behaviour. Tying them together is what produces bitmap paragraphs.
02 — SPACING & LAYOUTten values
Roughly geometric so adjacent steps are visibly different. A linear ramp gives values too close to tell apart, which is how spacing drifts.
--s4Icon to label
--s8Label to value, button gaps
--s12Tag row to heading
--s16Heading to body, card padding
--s24Component padding
--s32Between components
--s48Above a section heading
--s64Between case study sections
--s96Hero padding, page top/bottom
--s128Between major regions
Vertical rhythm
Space above a heading is 3–4× the space below it — that's what makes a heading attach to what it introduces. 64 above a section marker, 16 below the heading. 48 above H3, 12 below.
Containers
full bleedHero block, footer, flattened nav
1100pxCard grid, work index
720pxCase study page, default column
60ch / 52chProse cap / lead cap, regardless of container
Breakpoints
< 560Single column. Gutter 16. Section gap 64→48, hero 96→48. Display type drops hardest; body barely moves.
560–900Card grid two-up. Gutter 24.
> 900Full scale. Gutter 32. Hero splits, portrait right.
Rule — if a value isn't on the ramp it's wrong. No 11px, 15px, 19px. Mobile compresses large steps only; --s16 and below never change.

04 — THE SPRITE6×6 · one frame, everything
Buttons, bubbles, tabs, cards and fields share one 6×6 map stretched with border-image. Only the centre stretches. Each colour expands to four tones — a flat fill kills the bevel.
Rule — raised = interactive or containing. Sunk = pressed, recessed, failed, current page, or an input. Nothing else uses shading.

08 — ICONS8×8 · twenty
Sizing
Rendered at 8 / 16 / 24 / 32 / 48 only — anything between puts pixels on half-positions. Two-pixel stroke minimum. Icons inherit text colour. Never width: 1em.
Social marks — never pixelate LinkedIn, Behance or Medium logos. Use their official SVG at 14–24px in monochrome, always with a text label.

Both axes quantise

    
Time steps into frames and space snaps to the 4px grid. Stepping the timing but letting an element land on 37.5px still reads wrong.

  

  
Never step — page scroll, text being read, focus rings, form validation. Nothing runs past 12 frames. Reveals fire once on scroll-in, never on scroll-back.

19 — RULESthe whole list

  

    
Always

    
    
      
  • Pixel type on short strings only — five words maximum
    • 
      
  • Case study headings are full sentences carrying the finding, always Geist
    • 
      
  • Every spacing value comes from the ramp
    • 
      
  • Space above a heading is 3–4× the space below
    • 
      
  • Motion uses steps(); movement lands on multiples of 4px
    • 
      
  • Raised bevel for interactive, sunk for pressed / recessed / failed / current / input
    • 
      
  • Every colour expands to four tones before it touches a sprite
    • 
      
  • Outlines lighten to mid-grey on dark backgrounds
    • 
      
  • Scanline applies to a container as a whole, never its children
    • 
      
  • Icons render at whole multiples of 8 only
    • 
    

    
Never

    
    
      
  • Bitmap type in a paragraph, caption, or sentence-length heading
    • 
      
  • Type out body copy, or scanline a paragraph
    • 
      
  • Two saturated buttons side by side
    • 
      
  • Eased or smooth animation anywhere in the pixel layer
    • 
      
  • Flat neon as a bevel face — lime becomes the highlight, not the fill
    • 
      
  • Step page scroll, focus rings, or form validation
    • 
      
  • Off-ramp spacing — no 11px, 15px, 19px
    • 
      
  • Mute grey below 16px on anything but a label
    • 
      
  • Redraw a third-party brand mark as pixel art
