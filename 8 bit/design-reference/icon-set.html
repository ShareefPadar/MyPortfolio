ICON SET

Twenty icons drawn on an 8×8 grid. Everything else in the system lands on 4px; icons were the last primitive still borrowed from elsewhere.

01 — THE SET8×8 · shown at 24px
Note — every shape uses a two-pixel stroke so it survives at 16px. One-pixel strokes disappear on a phone.
02 — SIZESwhole multiples only
The grid is 8×8, so valid sizes are 8, 16, 24, 32, 48. Anything between — 18px, 20px, 22px — puts pixels on half-positions and the icon goes soft. Same rule as the button sprite.
Rule — never width: 1em on an icon. Set explicit px from the list.

Social marks — don't pixelate LinkedIn or GitHub logos. Brand marks have usage guidelines, and a redrawn one reads as sloppy rather than stylish. Use their official SVG at 16 or 24px in monochrome ink.
05 — RULESshort
  • Drawn on 8×8, rendered at 8 / 16 / 24 / 32 / 48 only
  • Two-pixel stroke minimum so shapes hold at 16px
  • Icons inherit text colour, never carry their own
  • Icons sit on the text baseline, not centred to the line box
  • An icon beside a label is decorative — aria-hidden="true"
  • An icon alone needs an accessible name
Never
  • Sizes between the multiples — no 18px, 20px, 22px
  • The same icon doing two jobs on one page
  • An icon-only button under 44×44px
  • Rotate an icon to make a new one — draw the new one
  • Redraw a third-party brand mark as pixel art
