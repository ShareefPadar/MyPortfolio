08 — RULESshort
  • Links are ink text with a blue rule, never blue text
  • External arrow on external links only
  • UI strings quoted from a product go in mono, so the reader knows it's real copy
  • Bullets are squares on the grid — never discs
  • Ordered lists use leading zeros to match section markers
  • Prose caps at 60ch, quotes at 52ch
Never
  • More than one pull quote per section
  • A smooth progress bar
  • Underline anything that isn't a link
  • Nest lists more than one level
