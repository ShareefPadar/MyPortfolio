07 — RULESshort
  • Focus is a blue notched plate 7px behind the component, instant, never suppressed
  • Inputs use the sunk bevel — a field is a recess
  • Labels are always visible; placeholders are examples, never labels
  • Errors name the problem and show the fix, in text and icon
  • Every interactive target is at least 44×44px
  • Loaders are segmented blocks — nothing rotates
Never
  • Placeholder-as-label
  • Red text alone to signal an error
  • Animate or delay a focus ring
  • Mute grey below 16px
  • Disable the submit button before the user has tried
