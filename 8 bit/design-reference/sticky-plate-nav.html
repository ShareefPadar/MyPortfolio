02WHY RÉSUMÉ IS A BUTTON

Every other nav item is a place you can be, so it can be sunk. Résumé is a file that downloads — there's no state where you're "on" it, and a sunk résumé would be lying about where you are.

Making it a compact blue button solves that and buys something else: it's the only always-visible call to action on the site, present on every page including deep inside a case study. The download glyph tells you it leaves the page before you tap it.

ONE CONSISTENT MEANING Sunk now means exactly one thing everywhere — pressed button, recessed screenshot, failed audit block, current page. No new vocabulary anywhere in the system.
03ENOUGH ROOM TO SCROLL

Filler below so the sticky behaviour has somewhere to go. Keep scrolling and watch the bar sit flat against the top while the content column stays where it is.

The flatten happens instantly rather than easing — consistent with the motion rule that nothing in the pixel layer interpolates. A smooth height transition here would be the single most obvious break in the system, because it's the element on screen the entire time.
