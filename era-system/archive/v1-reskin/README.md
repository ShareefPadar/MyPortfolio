# v1 reskin — archived

The first era system repainted one shared layout per era with tokens. Shareef rejected it
("for 8-bit I made one style doesn't mean all the eras should have the same layout"), and
every era is now its own design under `eras/<era>/`.

Kept for history only. Nothing builds from here. 1995 still uses `styles/core.css`,
`styles/eras/1995.css` and its sprites, which is why those stayed where they were.
