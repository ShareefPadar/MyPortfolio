## 1. Identity

**Reference point:** Windows 95, early-90s desktop software, the grey chrome of a 1995 PC
**One-line look:** Light page, grey raised plates, recessed screens, pixel statements, one dark hero and footer
**What arrives in this era:** Bevels. Raised and sunk depth, notched corners, window-like containers
**What leaves (vs. 1986):** Nothing is lost; depth is added on top of the flat pixel look

**Deliberately not period-accurate:** The palette (lime + blue) and the sentence face (Geist) are contemporary on purpose. 1995 is the flagship era — it has to read as a serious product designer's site, not a Windows 95 costume. The *structure* is 1995; the *colour and reading layer* are now.

**Evoke, don't copy:**
- No Windows 95 title bars, minimise/maximise/close buttons, or taskbar — rejected, see `DECISIONS.md`
- No MS Sans Serif, no Microsoft or Apple system fonts
- All icons and sprites are original pixel drawings

## 2. Fonts

| Role | Face | Licence | Why this face |
|---|---|---|---|

| Label | **Departure Mono** | SIL OFL · departuremono.com | Monospaced pixel face; reads as a separate register from the proportional statement face |
| Sentence | **Geist** 400 / 500 / 600 | SIL OFL · Vercel | Neutral, highly legible, already in the Vercel stack. Geist is 1995's choice only — other eras choose their own |

Self-host all three. Departure Mono is not on Google Fonts — download from the designer's site, never a mirror.

## 4. Frames

**Frame kind:** `sprite`

Two techniques, by component type:

| Component | Technique |
|---|---|
| Buttons, chat bubbles, inputs, checkboxes | **6×6 border-image sprite** (below) |
| Plates: cards, nav bar, bezel, rail | **Inset box-shadow bevel** via `.frame-raised` |
| Screenshot wells | **Sunk box-shadow** via `.frame-sunk` |

### 4.1 The sprite

```
BODY (6×6)          TAIL — taper (6×5)
. D D D D .         F F F F F F
D H H H S D         D F F F F S
D H F F S D         . D F F S D
D H F F S D         . . D F S D
D S S S S D         . . . D D .
. D D D D .
```

`D` outline · `H` highlight · `S` shade · `F` face · `.` transparent

- Scale 4 (24px sprite, 8px border) for default components; **scale 6** for large buttons — never upscale a scale-4 sprite
- `border-image-slice` = border width, `fill`, `stretch`
- **Sunk** = swap H and S, darken face 10%
- **Hover** = lighten face 14% (or the palette's `hover` override)
- Tail overlaps the bubble's bottom edge by 4px so the outline opens into it
- Built, never generated at runtime: edit `styles/eras/1995.sprites.json`, run `node scripts/build-sprites.mjs 1995`. It writes SVGs to `public/sprites/1995/` and the rules to `styles/eras/1995.sprites.css` (generated — never edit by hand)
- Components render `<button class="frame-control" data-fill="action">` and never see a colour

## 6. Motion

| Token | Value |
|---|---|
| `--reveal-anim` | `reveal-clip-1995, reveal-bands-1995` |
| `--reveal-duration` | `360ms, 480ms` |
| `--reveal-timing` | `steps(6, end), steps(1, end)` |
| `--statement-reveal` | `type` |
| `--type-speed` | `45ms` |
| `--hover-timing` | `steps(1, start)` — instant |

**Reveal technique — scanline:** content is clipped top-down over 6 discrete steps while horizontal bands thicken from 1px to solid, like a CRT resolving. Chosen over the dither dissolve.

**Statement reveal — typewriter:** one character per 45ms, blue block caret blinking at `steps(1)`, caret removed when the line completes.

**Other motion in this era:**
- Numerals: 4-frame pop with one frame of overshoot
- Bubble entrance: 4-frame scale, origin bottom-left
- Typing dots: `steps(1)`, 0.35s stagger, ink squares
- Loaders and scroll progress: segmented blocks, one per frame
- LED: blink at `steps(1)`, 2.6s — the only loop

**Both axes quantise:** time steps into frames *and* movement lands on multiples of 4px.

## 8. Era-specific rules

**Always in 1995:**
- Every value lands on the 4px grid
- Every animation uses `steps()`
- Raised = interactive/containing; sunk = pressed/recessed/input/failed/current
- Pixel icons at 8 / 16 / 24 / 32 / 48 only
- Sprites cached or pre-rendered

**Never in 1995:**
- Eased or smooth motion anywhere
- Rounded corners
- Window title bars or OS chrome controls
- `--accent` (lime) as a button face — it's a highlight, not an action
- Near-black outlines on `--bg-inverse` — use the dark palettes
- `--text-muted` lighter than `#5C5C52`
- Two sprite buttons inside one card
