# Era · 1986 — 8-bit game

**Status:** 🟦 Own design (v2) · `eras/1986/` · every page built: home, work, about, 9 case studies

## The idea

The portfolio *is* a game. Not a site with pixel decoration — a title screen, a menu, a dialogue box and a level select.

| Content | Becomes |
|---|---|
| Hero | **Title screen** — sprite portrait, centred headline, `PRESS START` flourish over the real "View work" button |
| Nav | **Menu bar** — a ▶ cursor marks hover, focus and the current page |
| Greeting | **RPG dialogue box** — speaker tag, text types itself, blinking ▼ |
| Selected work | **Level select** — stage cards with `WORLD 1-1` badges, ★ on role-relevant domains |
| NDA note | **Secret area** — 🔒 locked panel |
| Live products | **Bonus stages** |
| Footer | **Continue screen** |
| Whole page | Sits inside a black TV bezel |

## Type
Press Start 2P (statements, 16/24/32 only) · VT323 (labels, 20–22px) · IBM Plex Mono (reading, 16px). All verified OFL; see archive for glyph checks. Known quirk, accepted: Press Start 2P draws É small → "RéSUMé". Shareef chose to keep "Résumé" as written.

## Look
Indigo screen `#15153A`, black bezel. Every element wears one frame: 4px light outline + 4px dark inner line, notched corners, no light source. Primary buttons cyan `#3CC8FF` with dark text; lime `#CDF22B` for the ★, cursor, speaker tag and focus ring (4px, square — pixel era).

## Motion
- Headline types at 40ms/char; dialogue at 22ms — visual only, full text in the DOM
- Palette-fade reveals: 4 hard opacity steps
- `PRESS START` and ▼ blink **three times then stop** — anything blinking past 5s fails WCAG 2.2.2
- Pressed buttons shift 4px down-right

## Flavour text
`LEVEL SELECT`, `WORLD 1-1`, `PRESS START`, `SECRET AREA`, `BONUS`, the speaker tag — all `aria-hidden` ornament. None of it carries information; every real label comes from `content/site.json`.

## Fixed during build
- Speaker tag sat on the box edge and was sliced off by the notched clip-path → moved inside

## Phase 2 — home (translates 1995)
`eras/1986/layout.mjs` is the shell every 1986 page uses.
- **Portrait:** the real pixels at half resolution in four screen blues; hover or focus swaps to NES colours.
- **Guide (Clippy's lines):** an RPG text box, bottom-right. It types, shows ▼, then tucks down to its name tag. Tap the tag to talk again.
- **Cursor:** chunky 8×8 sprite in 3px pixels, snapped to an 8px grid; ▶ over anything clickable.
- **Nav:** a game menu with a ▶ cursor and ↑↓ keys; a START menu on phones.
- **Copy → Copied:** the button flashes lime.
- **Era switcher:** a `◀ 1986 ▶` option selector beside the brand opens a SELECT-YEAR box with a ▶ cursor and ★ on the current year. Arrival: CRT power-on.
- **Work:** a STAGE SELECT — category options with a ▶ cursor and a stage counter; WORLD 1 (three full stages) and WORLD 2 (small stages, dithered card when there's no screenshot).
- **About:** a CHARACTER PROFILE — Player 1 status screen beside the sprite, ABILITIES (numbered boxes), a QUEST LOG timeline on a dotted pixel trail, the quote in a dialogue box.
- **Case study:** a LEVEL — XP bar of 10 blocks for reading progress, a STATS box, the statement in a dialogue box, screens in a black bezel, a console-style prototype with a power LED, a BONUS box, NEXT LEVEL.
- **Home game (`game.mjs`):** SHIP THE BACKLOG, a brick breaker, sitting the way live's Dino Runner does. No box: the navy screen is the field, exactly the CONTINUE? box's width, and the paddle rides that box's top border. A dropped ball flashes the border red. Bricks are backlog tickets with punched ends; 4px pixels (3px on phones); square-wave beeps. Mouse or ← → to move, space or tap to launch; 3 lives; clearing the wall brings a faster one.

## Guide (v3)
The Narrator, a text-adventure voice (`content.guides.1986`). Same box: types out, ▼, tucks to a name tag. Under the line, a `>` command prompt: LOOK repeats the line for what's in view, WORK / ABOUT / HOME walk there, RESUME opens it, INVENTORY, HELP; anything else gets "I don't know that word."
